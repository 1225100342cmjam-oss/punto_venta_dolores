# Punto de Venta Dolorense (Flutter + SQLite + TDD)

## Cómo usarlo
1. Copia esta carpeta y, dentro de ella, genera las carpetas de plataforma:
   flutter create .
   (No sobrescribe lib/, test/ ni pubspec.yaml; si pregunta, conserva los tuyos.)
2. flutter pub get
3. flutter test      (dominio + datos deben quedar en verde)
4. flutter run
